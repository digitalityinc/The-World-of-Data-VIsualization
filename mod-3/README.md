# 📘 Module 3 – Matplotlib and NumPy

This module introduces **Matplotlib** and explains how plots are structured using figures, axes, and subplots.  
The focus this week is on **understanding how Matplotlib works conceptually**, so you can build clear and well-organized visualizations later.

> 📌 **Note:** This module is intentionally **tutorial-focused**.  
> A guided tutorial is the primary learning resource for this week.

---

## 🚀 Start Here (Recommended Order)

1. ▶️ **Watch the tutorial video + use the tutorial slide deck**  
   👉 Go to: **[`tutorial/`](./tutorial/)**

2. 🧠 **Follow along and pause often**  
   Pay attention to how figures, axes, and subplots are created and how they relate to each other.

3. ✏️ **Try small experiments on your own (optional)**  
   Modify example code from the tutorial to see how changes affect the plots.

---

✨ **By the end of this week, you will be able to:**

- 🧩 **Explain Matplotlib’s design structure**  
  Understand how figures, axes, ticks, and labels fit together.

- 📐 **Use `plt.subplots()` to organize plots**  
  Create single plots and multi-plot layouts in a clean and controlled way.

- 📊 **Visualize NumPy arrays with Matplotlib**  
  Turn array-based data into clear, readable charts.

---

## 📚 Topics Covered
- Matplotlib’s object hierarchy (Figure, Axes, Labels, Ticks)
- Creating plots with `plt.subplots()`
- Single vs. multiple subplots
- Using NumPy arrays in visualization
