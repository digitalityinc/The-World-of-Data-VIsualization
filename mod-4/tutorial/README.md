# 📘 module 3: Data Visualization with Matplotlib & NumPy

This lecture introduces how to use **Matplotlib** and **NumPy** to analyze data, with a focus on wine quality datasets.  

---

## 🎯 Learning Objectives
By the end of this lecture, you will be able to:
- Understand the **Matplotlib object hierarchy** (Figure, Axes, etc.).  
- Use **`plt.subplots()`** to create single and multiple plots.  
- Share axes across subplots for clearer comparisons.  
- Visualize arrays effectively with **Matplotlib and NumPy**:contentReference[oaicite:0]{index=0}.  

---

## 📚 Topics Covered
- Matplotlib basics: figures, axes, and plotting.  
- Creating subplots (stacked, horizontal, grid-based).  
- Sharing x/y axes across plots.  
- Applying NumPy arrays in visualization.
