# 📘 Module 6: Time Zones & Time Series Data

This lecture introduces **time zones**, **UTC**, and how to handle **time series data with time zone information** using Pandas.

---

## 🎯 Learning Objectives
By the end of this week, students should be able to:
- Understand the **concept of UTC** (Coordinated Universal Time) and its role in civil and scientific time.
- Work with **time zones** and their offsets in Pandas.
- Process and analyze **time series data** across different time zones.

---

## 📚 Topics Covered
- Introduction to Datetime in Pandas
- UTC and time zone offsets
- Recording how data changes as one travels through time zones
- Plot styles in Pandas for time series visualization
