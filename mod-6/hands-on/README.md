
# 📘 Module 6 – Hands-On: Time Zones & Time Series Data

This notebook provides practical exercises on handling **time zones** and analyzing **time series data** with Pandas. It uses **NIFTY stock market datasets** as examples and demonstrates various plotting techniques.  

---

## 🎯 Learning Objectives
By the end of this hands-on, you will be able to:
- Work with **Datetime objects** in Pandas and understand time zones.  
- Convert and compare dates using `pd.to_datetime()`.  
- Explore **NIFTY Bank and NIFTY IT stock data**.  
- Use Pandas’ built-in plotting for line, bar, histogram, KDE, and box plots.  
- Resample time series data (e.g., weekly averages) and visualize results.  

---

## 📚 Key Activities
- Import and inspect NIFTY datasets (`head()`, `dtypes`).  
- Parse and compare dates across time zones.  
- Generate different plot types with Pandas’ `.plot()` method.  
- Customize plots with parameters (`figsize`, `title`, `kind`).  

---

## ▶️ How to Use
1. Open the notebook in **Jupyter Notebook** or **JupyterLab**.  
2. Run each cell step by step to explore NIFTY stock data.
