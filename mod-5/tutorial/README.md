# 📘 Module 5: Exploring Pandas DataFrames & Missing Data

This lecture focuses on gaining a deeper understanding of **Pandas DataFrames**, exploring dataset properties, handling missing values, and making analysis more insightful with visualization and styling.

---

## 🎯 Learning Objectives
By the end of this week, students should be able to:
- Explore and describe the **major properties/features** of a dataset.
- Identify the **expected data types** (int, float, string, boolean).
- Detect **obvious missing data** with Pandas.
- Recognize **non-standard or hidden missing data** that Pandas can’t easily detect.
- Visualize missing values and apply **styling to Pandas DataFrames** for clarity.

---

## 📚 Topics Covered
- Standard vs. non-standard missing values
- Asking the right questions when exploring data
- Example: Street dataset with numeric, string, and categorical fields
- Using Pandas for visualization (plotting immigration and multi-country data)
- DataFrame styling and hover effects to improve readability
