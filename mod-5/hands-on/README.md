# 🧑‍💻 Module 5 – Hands-On: Exploring DataFrames & Missing Data

This Jupyter notebook is the **hands-on companion** to Module 5.  
It is designed to help you practice **exploring real datasets**, identifying **missing or messy data**, and using **visualization and styling** to better understand what’s going on.

The focus of this notebook is **asking good questions about data**, not just running code.

---

## 📂 What’s in This Notebook?

In `module5-hands-on.ipynb`, you will practice:

- Exploring the **basic properties** of a dataset (shape, columns, data types)
- Asking key questions like:
  - What information is available?
  - What looks suspicious or incomplete?
- Identifying **standard missing values** (e.g., `NaN`)
- Recognizing **non-obvious or hidden missing data**
- Visualizing missing values and data distributions
- Applying **DataFrame styling** to improve readability and interpretation

This notebook is intentionally exploratory — there is often **more than one correct way** to approach the data.

---

## 🚀 How to Use This Notebook

1. Open `module5-hands-on.ipynb` in Jupyter Notebook or JupyterLab.
2. Run the cells **in order**, reading the comments and prompts carefully.
3. Pause to think before running each section — don’t rush.
4. Try changing values, filters, or plots to see how the results change.

If something doesn’t behave as expected, that’s a learning opportunity.

---

## 🧠 What to Focus On

As you work through the notebook, focus on:

- How you decide **what to look at first** when given a new dataset
- The difference between *missing data* and *bad or inconsistent data*
- What Pandas can detect automatically — and what it can’t
- How visualization and styling help surface issues that tables alone may hide

---

## ✅ Tip

You are not expected to “fix” the dataset completely.  
The goal is to **build intuition** for data exploration and develop habits that help you avoid mistakes later in analysis and visualization.

If you feel stuck, revisit the **Module 5 tutorial video and slides**, then return and continue experimenting.
