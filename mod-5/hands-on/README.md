# 🧑‍💻 Module 4 – Hands-On: Pandas DataFrames, Queries, and Heatmaps

This Jupyter notebook is a **hands-on companion** to Module 4.  
It is designed to help you practice working with **Pandas DataFrames** and apply the concepts introduced in the tutorial and slides.

You’ll explore real data, experiment with queries, and create visualizations to uncover patterns.

---

## 📂 What’s in This Notebook?

In `module4_hands-on.ipynb`, you will practice:

- Creating **Pandas DataFrames** from example datasets
- Sorting and filtering data
- Using **`.query()`** for readable, SQL-like data filtering
- Performing **basic correlation analysis**
- Creating **heatmaps** to visualize relationships and trends
- Thinking about *why* certain visualizations are helpful for analysis

This notebook focuses on **exploration**, not perfection — feel free to experiment.

---

## 🚀 How to Use This Notebook

1. Open `module4_hands-on.ipynb` in Jupyter Notebook or JupyterLab.
2. Run the cells **in order**, reading the comments and instructions carefully.
3. Modify values, filters, or plots to see how the outputs change.
4. If something breaks, that’s okay — debugging is part of learning.

---

## 🧠 What to Focus On

As you work through the notebook, think about:

- How DataFrames make data easier to organize and query
- When `.query()` is clearer than bracket-based filtering
- What heatmaps reveal that tables alone do not
- How correlation can suggest relationships (but not causation)
