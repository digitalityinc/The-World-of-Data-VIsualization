# 📘 module 5 Hands-On: Pandas & Missing Data

This notebook provides practical exercises on handling and visualizing missing data in **Pandas DataFrames**.  

---

## 🎯 Learning Objectives
By the end of this hands-on, you will be able to:
- Detect **standard and non-standard missing values** in datasets.  
- Use Pandas methods (`.describe()`, `.isna()`, `.dropna()`) to explore data quality.  
- Recognize missing values that Pandas cannot automatically detect.  
- Apply **visualization tools** (e.g., `msno.bar`) to show missing data patterns.  
- Style and plot DataFrames for better insights.  

---

## 📚 Key Activities
- Import and explore datasets with missing values.  
- Compare outputs with and without missing data handling.  
- Visualize missing data using **Matplotlib** and **missingno**.  
- Work with categorical and numeric fields to analyze dataset properties.  

---

## ▶️ How to Use
1. Open the notebook in **Jupyter Notebook** or **JupyterLab**.  
2. Run the cells step by step.  
3. Modify the dataset or add new missing values to test Pandas’ detection.
