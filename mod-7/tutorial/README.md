# 📘 module 7: Data Visualization in Healthcare

This lecture explores **healthcare data formats**, visualization methods, and the tools commonly used in clinical and medical contexts.  

---

## 🎯 Learning Objectives
By the end of this week, students should be able to:
- Describe key **healthcare data formats** and their sources (EHR/EMR, disease registries, monitoring devices, hospital systems, billing/coding).  
- Understand how healthcare data can be transformed into **visual content** (infographics, charts, dashboards).  
- Identify **visualization use cases**: operational (real-time), strategic (trends over time), and analytical (advanced insights).  
- Recognize the **tools used in healthcare visualization** (Tableau, Domo, Bold BI, Python, R):contentReference[oaicite:0]{index=0}.

## 📚 Topics Covered
- Data sources in healthcare (EHR/EMR/EPRO, remote monitoring, hospital systems).  
- Uses of visualization: operational dashboards, strategic planning, analytical models.  
- Interactive dashboards, apps, and widgets for clinicians.
