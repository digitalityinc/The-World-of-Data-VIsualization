# The World of Data Visualization

Since 9th grade, I’ve been doing research at the **Perelman School of Medicine at the University of Pennsylvania**, where I’ve helped scientists make sense of data through visualization. Along the way, I’ve learned how powerful charts, plots, and visuals can be for turning raw numbers into real insights.

---

## Why This Repository?
I wanted to create a place where other students (and anyone curious!) can **learn data visualization step by step**. This repo is a mini-course that combines what I’ve learned in research and in the classroom — with explanations that are beginner-friendly but still grounded in real-world practice.

---

## What’s Inside?
This repo has **9 modules**, and each module includes:
- **Tutorial videos** (walkthrough-style explanations you can follow along with)
- **Tutorial slides** (concepts + examples)
- **Jupyter notebooks** (hands-on coding + practice tasks)
- **Helpful readings** (articles and papers I found useful)

---

## Module Overview (1–9)
- **Module 1: Introduction to Data Visualization**  
  Why we visualize data, how humans interpret visuals, and common chart mistakes to avoid.

- **Module 2: Data Structures in Python**  
  Core Python data structures and how they connect to NumPy for working with data.

- **Module 3: Matplotlib and NumPy**  
  Matplotlib’s design, `plt.subplots()`, and plotting efficiently using NumPy arrays.

- **Module 4: Data Visualization with Pandas & Heatmaps**  
  Pandas DataFrames, filtering with `.query()`, heatmaps, and correlation analysis.

- **Module 5: Exploring Pandas DataFrames & Missing Data**  
  How to explore datasets, detect hidden missing values, and visualize missingness clearly.

- **Module 6: Time Zones & Time Series Data**  
  Datetime in Pandas, UTC, time zone offsets, and plotting time series correctly.

- **Module 7: Data Visualization in Healthcare**  
  Healthcare data formats, dashboards, and real clinical/operational visualization use cases.

- **Module 8: Sensor Data in Healthcare**  
  Wearables and clinical sensors, sampling rates, time series signals, and real-world data volume challenges.

- **Module 9: Physical Simulation and Visualization**  
  Using computation to simulate physical systems and visualizing results to verify and understand behavior.

---

## How to Use
1. Start with **Module 1** and work your way through.
2. Watch the **tutorial video** first (quick overview + key ideas).
3. Review the **slides** for concepts and examples.
4. Do the **notebook** for hands-on practice.
5. Explore the **readings** if you want to dive deeper.
