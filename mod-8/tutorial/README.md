# 📘 module 8: Sensor Data in Healthcare

This lecture explores **sensors and sensor data** in the healthcare industry, including how they are captured, measured, and visualized to support patient monitoring and decision-making.  

---

## 🎯 Learning Objectives
By the end of this week, students should be able to:
- Describe the role of **sensors and sensor data** in healthcare.  
- Understand how sensor data are **captured, visualized, and measured** in clinical settings:contentReference[oaicite:0]{index=0}.  

---

## 📚 Topics Covered
- Applications of wearable smart devices in healthcare.  
- Categories of digital health data: **structured, semi-structured, unstructured**.  
- Measurement systems and **sampling rate considerations**.  
- Time series data from sensors.  
- Sensor classifications and healthcare use cases (e.g., ICU monitoring, biometric wearables).  
- Challenges with **data volume** and IT infrastructure in healthcare.  
- New biometric sensors enabling better care and advanced insights:contentReference[oaicite:1]{index=1}.
