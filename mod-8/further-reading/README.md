# 📚 Further Reading (Module 8)

This list is **optional** — it’s here if you want to explore real-world examples of sensor data in healthcare.
You don’t need to read everything. If you only pick one, start with the **population health** article for an accessible overview.

---

## 🏥 Real-World Use Case (Recommended)
A practical overview of how wearable sensor data is used at scale in healthcare systems.

- [**Wearable Sensors and Population Health (Sequenex)**](https://sequenex.com/integrating-wearable-sensor-data-into-population-health-management/)  
  Discover how wearable sensor data is integrated into **population health management**, offering clinical, behavioral, and environmental insights to support preventive care and resource planning.

---

## 🧪 Research Deep Dive (Optional)
A more technical research article on next-generation wearable sensor technology.

- [**Wearable Sensors for Telehealth Based on Emerging Materials and Nanoarchitectonics** *(npj Flexible Electronics)*](https://doi.org/10.1038/s41528-023-00261-4)  
  Explore cutting-edge wearable sensors built with **2D materials**, capable of monitoring vital signs (temperature, heart rate, sweat biomarkers) and enabling telehealth through enhanced sensitivity and flexibility.
